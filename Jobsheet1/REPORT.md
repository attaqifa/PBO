## 5. Pertanyaan

1. Jelaskan perbedaan antara object dengan class!  
**Jawab:** Class adalah cetakan (blueprint) dari suatu objek, sedangkan Object adalah bentuk nyata hasil instansiasi dari class yang memiliki atribut dan method.
2. Jelaskan alasan gear dan brand dapat menjadi atribut dari object Bike!  
**Jawab:** Karena gear dan brand merupakan state, yaitu ciri-ciri atau atribut yang melekat pada objek Bike.
3. Sebutkan salah satu kelebihan utama dari pemrograman berorientasi objek dibandingkan dengan pemrograman prosedural!  
**Jawab:** Program lebih fleksibel dan modular, sehingga jika ada perubahan fitur tidak akan mengganggu keseluruhan program. Selain itu kode lebih tertata dan efisien.
4. Apakah diperbolehkan melakukan pendefinisian dua buah atribut dalam satu baris kode seperti “public String nama, alamat;”?  
**Jawab:** Ya, diperbolehkan dalam Java selama kedua atribut memiliki tipe data yang sama.
5. Pada class RoadBike, jelaskan alasan atribut brand, speed, dan gear tidak lagi ditulis di dalam class tersebut!  
**Jawab:** Karena class RoadBike menggunakan konsep inheritance (extends Bike), sehingga otomatis mewarisi atribut dari class Bike.
